## Implementation decisions

| Topic | Decision | Where |
| --- | --- | --- |
| ACWR | EWMA with lambda = 2/(N+1), 7-day acute / 28-day chronic. No ratio until 28 days of history. | `analytics/load.py` |
| Monotony | Mean / population SD of the 7 daily loads, rest days included as 0. Undefined (None) if SD = 0. | `analytics/load.py` |
| PHV window | Maturity offset within -1.0 to +1.0 years. Plan does not fix the width. | `analytics/maturation.py` |
| Mirwald | Male and female equations implemented. Estimate SE ~0.5 years, so it's shown as an estimate. | `analytics/maturation.py` |
| HRV baseline | Previous 7 days (not including today), sample SD. | `analytics/readiness.py` |
| Readiness weights | 0.40 / 0.35 / 0.25 in `config/readiness.yaml`, labelled as team defaults. | `config/readiness.yaml` |
| Test norms | **Placeholders**, calibrated only so the plan's example (30 m in 4.35 s = 72nd pct U17) holds. Must be replaced with published norms. | `config/norms.yaml` |
| Policy gaps | Load cuts of 20% or less and RPE changes beyond +/-1 are not in the plan's table. Both go to the coach (fail safe). Any active safety flag escalates every proposal for that player. | `agents/coordinator.py` |
| Simulator randomness | World randomness is keyed by (player, day, purpose), so baseline and agent policies face identical fixtures, sleep noise and injury dice (common random numbers). | `simulator/season.py` |
| Simulated sitting height | Generated by inverting Mirwald so the estimate equals the true offset plus a per-player bias (SD 0.4 y). Clipped to +/-3 years, where Mirwald is valid. | `simulator/season.py` |

## Open questions for sign-off

1. **Monotony target is unreachable as written.** With 4 sessions + 1 match and 2 rest days a
   week, monotony never exceeds 2 in the baseline, so "≥ 40% fewer weeks with monotony > 2"
   can't be measured. Options: lower the threshold (e.g. 1.5), compute monotony over training
   days only, or replace the metric with strain.
2. **PHV window width.** -1 to +1 years is common, but some academies use +/-0.5. This changes
   how many players are restricted.
3. **ACWR spike base rate is low (~6% of player-weeks).** The "≥ 50% fewer than baseline" target
   rests on ~60 player-weeks per season; consider reporting across several seeds.
4. **Norm sources.** Who finds published U13-U19 norms for 10 m / 30 m sprint, CMJ and Yo-Yo IR1?
